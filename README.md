# NanoMAP Data Analysis Workflow Repository

This repository contains codes used in the NanoMAP data analysis workflow. 

Workflow requirements:
1. **Imaris** Image Analysis Software, with the Imaris for Cell Biologists package (https://imaris.oxinst.com/products/imaris-for-cell-biologists).
2. **Matlab** (https://www.mathworks.com/?s_tid=gn_logo).
3. **Python** and **Jupyter Notebook**. One-step installation through **Anaconda** (https://www.anaconda.com/docs/getting-started/installation).

Environment info:
Tested on Imaris v9.9 and v.10.0, Matlab R2021a, Python 3.13.5.

Repository content:
* 1. ***User_Guide-NanoMAP_Analysis_Workflow.pdf***
* 2. The Imaris-XTension folder contains matlab codes for XTensions "Distance Transformation In And Out", "Surface Index Mask", and "Nearby Surfaces". 
* 3. The Python_code folder contains Jupyter Notebook files for analysis of "MV Enrichment", "MV and Cluster", "Nearby Surface" and "Cell Scoring". 

How to use: 

1. Read ***User_Guide-NanoMAP_Analysis_Workflow.pdf*** for the overview of all analysis steps of the workflow. The codes in this repository are highlighted in yellow in this guide. 
2. Install the Imaris XTensions following the installation instructions of each XTension.
3. Follow the steps listed in ***User_Guide-NanoMAP_Analysis_Workflow.pdf***
